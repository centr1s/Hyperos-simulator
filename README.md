# HyperOS Simulator

Небольшой фанатский симулятор интерфейса Xiaomi HyperOS, работающий прямо в браузере.

## О проекте
Изначально проект был собран в Scratch примерно за 6 часов, а затем портирован в единый HTML-файл ради эксперимента.

* **Оригинальный проект на Scratch:** [Открыть в Scratch](https://scratch.mit.edu/projects/1283461915/editor/)

### Что есть внутри:
* Экран блокировки с часами и рабочий стол
* Имитация стандартных приложений: камера, браузер, сообщения и настройки
* Меню питания с перезагрузкой и выключением
* Встроенные системные звуки

> **Дисклеймер:** Скорее всего, это первая и одновременно последняя версия этой программы, так что относитесь к мелким багам с пониманием 😄

## Как запустить
* **Онлайн:** откройте ссылку в разделе **Deployments / GitHub Pages** (если включено в настройках репозитория).
* **Локально:** скачайте файл `index.html` и откройте его двойным кликом в любом современном браузере.
